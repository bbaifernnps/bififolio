Typography

Inter is the primary UI typeface across both apps; default body text is 14px. Every product screen (Monitoring, RBAC, Group Management, Login) uses it. The file defines no named text styles, so the scale below is promoted from the Typography variable collection into reusable classes. Thai is the default locale (PRD D19).
